# autopilot.ee – DayOne onepager

Leht ehitatakse Jekylliga. GitHub Pages teeb seda ise, eraldi build-sammu pole.

| Mida muudad | Fail |
|---|---|
| Eestikeelne tekst | `_data/et.yml` |
| Ingliskeelne tekst | `_data/en.yml` (samad võtmed mis `et.yml`-is) |
| Kujundus, HTML, CSS | `_layouts/onepager.html` (üks fail, kehtib mõlemale keelele) |
| Jagamispildid | `og-image.png` (ET), `og-image-en.png` (EN) |

Aadressid: `https://autopilot.ee/` (ET) ja `https://autopilot.ee/en/` (EN).

Reegel: kui lisad `et.yml`-i uue teksti, lisa sama võtmega tõlge ka `en.yml`-i.
